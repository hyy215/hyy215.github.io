AgentScope 2.0 源码解读 · 模型与消息 ​

备注 · 本文的源码分析基于 AgentScope 2.0.12dev（提交 7b5b37d5）。

在 AgentScope 应用中，模型和消息分别对应推理能力和对话数据。

  • 模型根据输入生成回复。应用通过聊天模型适配器发起请求，并从返回的 ChatResponse 中读取结果。
  • 消息承载用户输入、系统指令和历史回复。每条 Msg 记录角色和内容块，多条消息可以一起作为模型调用的上下文。

例子 ​

这个例子把「今天天气很好」翻译成英文，并打印模型返回的译文。

  • DashScopeChatModel 是用于调用 DashScope 聊天模型的适配器。
  • UserMsg() 把翻译请求构造成一条用户消息。
python
import asyncio
import os

from agentscope.credential import DashScopeCredential
from agentscope.message import TextBlock, UserMsg
from agentscope.model import DashScopeChatModel


async def main() -> None:
    model = DashScopeChatModel(
        # 从环境变量读取 DashScope API 密钥，作为调用凭据。
        credential=DashScopeCredential(api_key=os.environ["DASHSCOPE_API_KEY"]),
        model="qwen-plus",  # 指定要调用的模型
        stream=False,  # 等待完整响应
    )

    # UserMsg() 将消息角色设为 user。
    message = UserMsg(
        name="reader",  # 发送者名称
        content="请把「今天天气很好」翻译成英文。",  # 发给模型的翻译请求
    )

    # 模型接口接收消息列表，单条消息也要放进列表。
    response = await model([message])

    # 从 ChatResponse 提取文本块并打印译文，例如 The weather is nice today.
    for block in response.content:
        if isinstance(block, TextBlock):
            print(block.text)


asyncio.run(main())

消息模块 ​

三种消息角色 ​

AgentScope 通过 role 字段标明对话信息的来源，支持以下三种角色。

角色（role）消息构造函数承载的信息
userUserMsg()用户的输入
assistantAssistantMsg()助手的回复
systemSystemMsg()提供给模型的系统指令

内容块类型 ​

ContentBlock 是以下六种内容块的联合类型。每个块通过 type 标明自己的类型。

内容块type承载内容
TextBlocktext文本，包括正文和 Markdown 代码块
ThinkingBlockthinking模型输出的推理内容
DataBlockdata图片、音频、视频等数据
HintBlockhint智能体运行时提供给模型的提示
ToolCallBlocktool_call工具名称和调用参数
ToolResultBlocktool_result工具执行的结果和状态

字段说明和示例见 AgentScope 官方文档 · 内容块。

Msg 的数据结构 ​

三种角色的构造函数都返回同一种 Msg。

  • name 记录发送者。
  • id 标识这条消息。
  • content 保存消息的内容块列表。

内容块转换 ​

UserMsg()、AssistantMsg() 和 SystemMsg() 都会调用 _to_blocks()。当 content 是字符串时，它会将字符串封装成只含一个 TextBlock 的列表。

python
def _to_blocks(content: str | list) -> list:
    if isinstance(content, str):
        return [TextBlock(text=content)]
    return content


class TextBlock(BaseModel):
    type: Literal["text"] = "text"
    text: str
    id: str = Field(default_factory=_generate_id)
    created_at: str = Field(default_factory=_generate_timestamp)
    finished_at: str | None = None

内容校验 ​

Msg 解析完字段后，validate_role_content() 会按 role 检查 content 允许包含的内容块。

python
@model_validator(mode="after")
def validate_role_content(self) -> Self:
    match self.role:
        case "user":
            _assert_user_content_blocks(self.content)
        case "system":
            _assert_system_content_blocks(self.content)
        case "assistant":
            # 助手消息允许所有 ContentBlock 类型。
            pass
    return self


# 用户消息只允许文本块（text）和数据块（data）。
def _assert_user_content_blocks(content: Sequence[ContentBlock]) -> None:
    for block in content:
        if block.type not in ["text", "data"]:
            raise ValueError(
                "User message can only contain text blocks or data blocks.",
            )


# 系统消息只允许文本块（text）。
def _assert_system_content_blocks(
    content: Sequence[ContentBlock],
) -> None:
    for block in content:
        if block.type not in ["text"]:
            raise ValueError("System message can only contain text blocks.")

模型模块 ​

供应商适配 ​

AgentScope 提供多个聊天模型适配器。它们都继承 ChatModelBase，共用 __call__() 入口。各适配器通过自己的 _call_api() 按供应商格式组装请求、调用 API，并将响应解析成框架统一的 ChatResponse。

供应商聊天模型适配器调用的 API
DashScopeDashScopeChatModelDashScope 的 OpenAI 兼容 Chat Completions
OpenAIOpenAIChatModelOpenAI Chat Completions
AnthropicAnthropicChatModelAnthropic Messages

接口调用 ​

ChatModelBase.__call__() 通过当前适配器的 _call_api() 向模型发送请求。等待 _call_api() 返回期间，基类会按配置重试适配器声明为可重试的异常。异步生成器返回后，读取流时遇到的网络异常会传给调用方，即使还没收到第一帧。

python
# ChatModelBase.__call__() 源码节选，省略重试和异常处理。
res = await self._call_api(
    self.model,
    messages=messages,
    tools=tools,
    tool_choice=tool_choice,
    **kwargs,
)

# 非流式响应直接返回。
if isinstance(res, ChatResponse):
    return res

# 流式响应返回异步生成器，省略 _stream() 的实现。
return _stream()

源码 · ChatModelBase.__call__

例如，DashScopeChatModel._call_api() 通过 OpenAI Python SDK 向 DashScope 发送请求，并将接口响应转换成 ChatModelBase 使用的 ChatResponse。

python
async def _call_api(
    self,
    model_name: str,
    messages: list[Msg],
    tools: list[dict] | None = None,
    tool_choice: ToolChoice | None = None,
    **kwargs: Any,
) -> ChatResponse | AsyncGenerator[ChatResponse, None]:
    # 转换成 DashScope 接口需要的消息格式。
    # messages 字段参考 https://help.aliyun.com/zh/model-studio/qwen-api-via-openai-chat-completions
    formatted_messages = await self.formatter.format(messages)

    request_kwargs: dict[str, Any] = {
        "model": model_name,
        "messages": formatted_messages,
        "stream": self.stream,
    }

    # 省略可选请求参数和工具配置。
    start_datetime = datetime.now()
    response = await self.client.chat.completions.create(**request_kwargs)

    if self.stream:
        return self._parse_stream_response(start_datetime, response)

    return self._parse_completion_response(start_datetime, response)

响应解析 ​

ChatResponse 是框架统一的模型响应结构，用内容块列表保存模型输出，并记录用量和结束状态。

@dataclass
class ChatResponse(DictMixin):
    # 模型响应的内容块列表。
    content: List[TextBlock | ToolCallBlock | ThinkingBlock | DataBlock]

    is_last: bool  # 是否为最后一帧。
    usage: ChatUsage | None = field(default_factory=lambda: None)  # 用量统计。

    # 最后一帧的结束原因，COMPLETED 或 INTERRUPTED。
    finished_reason: FinishedReason = field(
        default_factory=lambda: FinishedReason.COMPLETED,

源码 · ChatResponse

非流式调用中，ChatModelBase.__call__() 直接返回适配器转换后的 ChatResponse。流式调用中，基类通过 _stream() 遍历适配器返回的流，边转发响应边收集增量。

  • is_last 表示当前帧是否为最后一帧。值为 False 时，边累积数据，边转发有内容的增量帧。
  • 有些适配器只发内容增量，末尾可能补发用量统计。流正常结束时若仍未收到 is_last=True 的帧，基类用 build() 组装最终的 ChatResponse。
  • 用户取消正在等待下一帧的任务时，_stream() 捕获 CancelledError，标记 INTERRUPTED 并清理迭代器，再用 build() 把已累积的内容组装成最终帧。
python
async def _stream() -> AsyncGenerator[ChatResponse, None]:
    yield_acc_res = True
    acc_res = _StreamAccumulator()
    emitted = False
    try:
        async for chunk in res:
            if not chunk.is_last:
                acc_res.append_chat_response(chunk)
                acc_res.id = chunk.id
                if not chunk.content:
                    continue
            else:
                yield_acc_res = False
            emitted = True
            yield chunk
    except asyncio.CancelledError:
        acc_res.finished_reason = FinishedReason.INTERRUPTED
        yield_acc_res = True
    except Exception as e:
        normalized_error = self._normalize_exception(e)
        if isinstance(normalized_error, ContentBlockedError):
            normalized_error.partial_output |= emitted
        if normalized_error is not e:
            raise normalized_error from e
        raise
    finally:
        # 省略关闭支持 aclose() 的底层迭代器。
        ...

    if yield_acc_res:
        yield acc_res.build()

源码 · _stream

_stream() 通过 _StreamAccumulator 收集增量并组装响应。下面模拟两帧，每帧都包含两个文本块，第二帧交换了两个块的顺序。

python
from agentscope.message import TextBlock
from agentscope.model import ChatResponse
from agentscope.model._utils import _StreamAccumulator

frames = [
    [TextBlock(id="a", text="A1"), TextBlock(id="b", text="B1")],
    [TextBlock(id="b", text="B2"), TextBlock(id="a", text="A2")],
]

acc = _StreamAccumulator()
for blocks in frames:
    acc.append_chat_response(ChatResponse(content=blocks, is_last=False))

response = acc.build()
print([(block.id, block.text) for block in response.content])
# [('a', 'A1A2'), ('b', 'B1B2')]

  • 在这个文本示例中，append_chat_response() 按 TextBlock.id 收集各帧的文本片段。同一 ID 的片段按到达顺序追加，因此第二帧交换两个块的位置后，仍能得到 A1A2 和 B1B2。
  • build() 按内容块首次出现的顺序生成最终的 ChatResponse。
python
# 源码节选，省略初始化和内容块类型变化的处理。
class _StreamAccumulator:
    def append_chat_response(self, chat_response: ChatResponse) -> Self:
        for block in chat_response.content:
            acc = self._blocks.get(block.id)
            if acc is None:
                fields = block.model_dump()
                if isinstance(block, TextBlock):
                    acc = _AccTextBlock(**{**fields, "text": []})
                # 省略其他类型的累积对象初始化。
                self._blocks[block.id] = acc

            acc.append(block)  # type: ignore[arg-type]

        # 省略用量更新。
        return self

    def build(self) -> ChatResponse:
        # 省略响应 ID 和用量字段。
        return ChatResponse(
            content=[_.build() for _ in self._blocks.values()],
            is_last=True,
            finished_reason=self.finished_reason,
        )

源码 · _StreamAccumulator

以文本块为例，_AccTextBlock 把片段追加到列表，等到 build() 时一次拼接，避免反复复制已累积的字符串。

python
# 源码节选，省略文档字符串。
class _AccTextBlock(TextBlock):
    text: list[str] = Field(  # type: ignore[assignment]
        default_factory=list,
    )

    def append(self, block: TextBlock) -> None:
        self.text.append(block.text)

    def build(self) -> TextBlock:
        return TextBlock(**{**self.model_dump(), "text": "".join(self.text)})
