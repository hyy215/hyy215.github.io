AgentScope 2.0 源码解读 · 上下文与状态 ​

备注 · 本文的源码分析基于 AgentScope 2.0.12dev（提交 7b5b37d5）。

上一篇让模型把「今天天气很好」翻译成英文，并从 ChatResponse 中读出了译文。要把这轮对话保存在会话历史里，用户的请求和助手的回复该怎样写入 AgentState？

例子 ​

先用翻译请求初始化 AgentState，再把译文追加到助手消息中。示例直接使用上一篇给出的译文，可以独立运行。

python
from agentscope.message import TextBlock, UserMsg
from agentscope.state import AgentState

# 用用户消息初始化 AgentState。
message = UserMsg(
    name="reader",
    content="请把「今天天气很好」翻译成英文。",
)
state = AgentState(context=[message])

# append_context 将译文写入本次回复的助手消息。
translation = TextBlock(text="The weather is nice today.")
state.append_context("translator", [translation])

for msg in state.context:
    print(f"{msg.role}: {msg.get_text_content()}")

AgentState 说明 ​

AgentState 保存一个 Agent 在某个会话中的上下文信息，主要有以下几个属性：

  • session_id 是当前会话的标识，在创建会话时确定。同一会话的多次回复沿用这个 ID。
  • context 按对话顺序保存当前会话中尚未压缩的用户和助手消息。压缩后，summary 保存摘要，context 只保留仍需传给模型的消息内容。
  • reply_context 记录最近一次回复的标识和进度。
  • summary 保存较早对话的摘要，由 Agent 在压缩历史消息时更新，具体过程见第 06 篇《上下文管理与中间件》。
  • tasks_context 保存任务工具维护的当前任务列表。
  • tool_context 记录已启用的工具组和文件读取缓存。
  • permission_context 保存权限模式、附加工作目录和权限规则。
  • middle_context 保存中间件在同一会话的多次回复之间复用的数据。
python
# AgentState 的字段声明
class AgentState(BaseModel):
    session_id: str = Field(default_factory=_generate_id)
    summary: str | list[TextBlock | DataBlock] = ""
    context: list[Msg] = Field(default_factory=list)
    reply_context: ReplyContext = Field(default_factory=ReplyContext)
    permission_context: PermissionContext = Field(
        default_factory=PermissionContext,
    )
    tool_context: ToolContext = Field(default_factory=ToolContext)
    tasks_context: TaskContext = Field(default_factory=TaskContext)
    middle_context: dict[str, Any] = Field(default_factory=dict)

context 与会话消息 ​

一次问答中，state.context 保存两类消息。

  • 用户消息（user）保存用户输入，每条用户消息单独追加到列表。
  • 助手消息（assistant）保存当前 Agent 本次回复的内容。模型生成的文本、工具调用及对应的工具结果等内容块会依次追加到同一条助手消息中。

消息的存储结构 ​

state.context 以 list[Msg] 的形式按对话顺序存储消息。

读取和追加助手消息 ​

本次回复的助手消息保存在 state.context 中，消息 ID 取自 state.reply_context 的 reply_id 字段。

get_reply_message(name)：查找指定助手的当前回复消息。 ​

从后往前遍历 state.context，返回第一条角色为 assistant、发送者名称为 name 且消息 ID 等于 state.reply_id 的消息。

python
def get_reply_message(self, name: str) -> Msg | None:
    return next(
        (
            message
            for message in reversed(self.context)
            if message.id == self.reply_id
            and message.role == "assistant"
            and message.name == name
        ),
        None,
    )

append_context(name, blocks)：为当前回复追加内容块。 ​

如果本次回复中已有该助手的消息，就向其中追加内容块，否则创建一条助手消息来保存这些内容块。

python
def append_context(
    self,
    name: str,
    blocks: list[
        TextBlock | DataBlock | HintBlock | ToolCallBlock | ToolResultBlock
    ],
) -> None:
    message = self.get_reply_message(name)
    if message is not None:
        message.content.extend(blocks)
    else:
        self.context.append(
            Msg(
                id=self.reply_id,
                role="assistant",
                name=name,
                content=blocks,
            ),
        )

查询工具调用状态 ​

state.context 还保存了工具调用的请求和结果，可以通过 AgentState 提供的三个方法查询当前回复中的工具调用状态。

get_unfinished_tool_calls(name)：查找尚无结果的工具调用。 ​

  • tool_call 表示模型发出的工具调用请求。
  • tool_result 表示对应的执行结果。
  • 在指定助手的当前回复中，返回所有尚无对应结果的工具调用请求。
python
def get_unfinished_tool_calls(self, name: str) -> list[ToolCallBlock]:
    last_msg = self.get_reply_message(name)
    if last_msg is None:
        return []
    result_ids = {b.id for b in last_msg.get_content_blocks("tool_result")}
    return [
        tc
        for tc in last_msg.get_content_blocks("tool_call")
        if tc.id not in result_ids
    ]

get_awaiting_tool_calls(name)：查找正在等待外部响应的工具调用。 ​

在指定助手的当前回复中，返回正在等待用户确认或已提交给外部执行但尚未收到结果的工具调用请求。

python
def get_awaiting_tool_calls(self, name: str) -> list[ToolCallBlock]:
    last_msg = self.get_reply_message(name)
    if last_msg is None:
        return []
    result_ids = {b.id for b in last_msg.get_content_blocks("tool_result")}
    return [
        tc
        for tc in last_msg.get_content_blocks("tool_call")
        if tc.state == ToolCallState.ASKING
        or (
            tc.state == ToolCallState.SUBMITTED and tc.id not in result_ids
        )
    ]

reply_context 当前回复 ​

ReplyContext 字段说明 ​

state.reply_context 是 AgentState 的公开字段，记录一次回复的标识、迭代进度和结构化输出。

  • reply_id 标识本次回复，也是对应助手消息的 ID。
  • cur_iter 记录本次回复已完成的迭代轮数。
  • structured_schema 定义本次回复要求的输出格式。校验失败时，模型可以在剩余的迭代轮次内根据错误原因修正结果并重新提交。
  • structured_output 在校验通过后保存结果字典。
python
# ReplyContext 节选，保留字段声明和 structured_schema 的序列化逻辑。
class ReplyContext(BaseModel):
    reply_id: str = Field(default_factory=_generate_id)
    cur_iter: int = 0
    structured_schema: Type[BaseModel] | dict | None = None

    # 导出状态时，将 structured_schema 中的 Pydantic 模型类转成 JSON Schema 字典，已有字典或 None 则原样返回。
    @field_serializer("structured_schema")
    def _serialize_structured_schema(
        self,
        value: Type[BaseModel] | dict | None,
    ) -> dict | None:
        return value.model_json_schema() if isinstance(value, type) else value

    structured_output: dict | None = None

Agent 开始新回复时，会创建新的 ReplyContext，为这次回复生成一个新的 reply_id。

TaskGet.call() 按 ID 查看任务 ​

工具按 task_id 查找任务，通过 ToolChunk 返回任务详情或未找到任务的错误信息。

python
class TaskGet(_TaskToolBase):
    async def call(
        self,
        task_id: str,
        _agent_state: AgentState,
    ) -> ToolChunk:
        # 省略参数检查
        task = None
        for t in _agent_state.tasks_context.tasks:
            if t.id == task_id:
                task = t
                break

        if task is None:
            return ToolChunk(
                content=[
                    TextBlock(text="Task not found"),
                ],
                state=ToolResultState.ERROR,
            )

        lines = [
            f"Task (id={task.id}): {task.subject}",
            f"Status: {task.state}",
            f"Description: {task.description}",
        ]
        # 省略负责人、依赖关系和元数据的展示
        return ToolChunk(
            content=[
                TextBlock(text="\n".join(lines)),
            ],
        )

TaskList.call() 列出任务概览 ​

工具遍历任务列表，通过 ToolChunk 按行返回每条任务的编号、状态和标题等信息。

python
class TaskList(_TaskToolBase):
    async def call(self, _agent_state: AgentState) -> ToolChunk:
        # 省略参数检查
        if len(_agent_state.tasks_context.tasks) == 0:
            return ToolChunk(
                content=[TextBlock(text="No tasks available.")],
            )

        tasks = []
        for task in _agent_state.tasks_context.tasks:
            owner = f"({task.owner})" if task.owner else ""
            blocked = (
                f'[blocked by {", ".join(task.blocked_by)}]'
                if task.blocked_by
                else ""
            )
            tasks.append(
                f"{task.id} [{task.state}] {task.subject}{owner}{blocked}",
            )

        return ToolChunk(
            content=[
                TextBlock(text="\n".join(tasks)),
            ],
        )

class TaskUpdate(_TaskToolBase):
    async def call(
        self,
        _agent_state: AgentState,
        task_id: str,
        subject: str | None = None,
        description: str | None = None,
        add_blocks: list[str] | None = None,
        status: Literal["pending", "completed", "in_progress", "deleted"]
        | None = None,
        add_blocked_by: list[str] | None = None,
        owner: str | None = None,
        metadata: dict | None = None,
    ) -> ToolChunk:
        # 节选状态更新分支。index 是按 task_id 找到的位置，updated_fields 记录已改动的字段。
        if status:
            if status == "deleted":
                _agent_state.tasks_context.tasks.pop(index)
                # 从其余任务的依赖记录中移除这个 ID
                for task in _agent_state.tasks_context.tasks:
                    if task_id in task.blocks:
                        task.blocks.remove(task_id)

                    if task_id in task.blocked_by:
                        task.blocked_by.remove(task_id)
                return ToolChunk(
                    content=[
                        TextBlock(
                            text=f"Task (id={task_id}) has been deleted.",

                for task in _agent_state.tasks_context.tasks:
                    if task_id in task.blocked_by:
                        task.blocked_by.remove(task_id)
        # 省略其余字段的更新和工具响应的组装

文件读取缓存 ​

ToolContext.get_cache() 读取缓存 ​

  • 按文件的绝对路径 file_path 查找缓存记录。
  • 如果文件修改时间 mtime 与记录的 updated_at 一致，将记录移到列表末尾并返回。
  • 如果修改时间不一致，移除这条过期记录并返回 None。
python
async def get_cache(
    self,
    file_path: str,
    mtime: float | None = None,
) -> ReadCacheEntry | None:
    for entry in self.read_file_cache:
        if entry.file_path == file_path:
            if mtime is None:
                try:
                    mtime = await aiofiles.os.path.getmtime(file_path)
                except Exception:
                    mtime = None

            # 等待文件系统返回时，其他调用可能已经移除了这条记录
            if entry not in self.read_file_cache:
                return None

            self.read_file_cache.remove(entry)
            if mtime != entry.updated_at:
                return None
            self.read_file_cache.append(entry)
            return entry
    return None

ToolContext.cache_file() 写入缓存 ​

  • 移除同一路径的旧缓存。
  • 文件大小不超过 max_cache_bytes 时，写入新缓存。
python
async def cache_file(
    self,
    file_path: str,
    lines: list[str],
    mtime: float | None = None,
) -> None:
    if mtime is None:
        try:
            mtime = await aiofiles.os.path.getmtime(file_path)
        except Exception:
            return

    new_entry_bytes = (
        sum(len(line.encode("utf-8")) for line in lines) / 1024
    )

    self.read_file_cache = [
        entry
        for entry in self.read_file_cache
        if entry.file_path != file_path
    ]
    if new_entry_bytes > self.max_cache_bytes:
        return

    # 省略按文件数和总大小从列表头部淘汰旧记录的循环
    self.read_file_cache.append(
        ReadCacheEntry(
            lines=lines,
            updated_at=mtime,
            bytes=new_entry_bytes,
            file_path=file_path,
        ),
    )

添加规则与检查调用权限 ​

Agent 在初始化时将 self.state.permission_context 传给 PermissionEngine。权限引擎通过这份配置添加规则和检查调用权限。

  • add_rule(rule) 将规则追加到对应工具的规则列表。
  • check_permission(tool, tool_input) 异步返回 PermissionDecision，说明本次调用可以执行、应被拒绝，还是需要用户确认。具体判断过程将在第 05 篇《权限与工作空间》中展开。
python
class PermissionEngine:
    def __init__(
        self,
        context: PermissionContext,
    ) -> None:
        self.context = context

    # add_rule 节选，保留允许执行的分支
    def add_rule(self, rule: PermissionRule) -> None:
        if rule.behavior == PermissionBehavior.ALLOW:
            if rule.tool_name not in self.context.allow_rules:
                self.context.allow_rules[rule.tool_name] = []
            self.context.allow_rules[rule.tool_name].append(rule)
        # 省略 DENY 和 ASK 分支

    # check_permission 节选，保留默认模式的分支
    async def check_permission(
        self,
        tool: ToolBase,
        tool_input: dict[str, Any],
    ) -> PermissionDecision:
        mode = self.context.mode
        if mode == PermissionMode.DEFAULT:
            return await self._check_default(tool, tool_input)
        # 省略其他模式的分支
