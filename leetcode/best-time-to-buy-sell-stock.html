买卖股票的最佳时机 IV：从题意理解状态机 DP ​

Algorithm动态规划状态机

1. 题目：188. 买卖股票的最佳时机 IV ​

给定一个整数 k 和一个整数数组 prices，其中 prices[i] 表示某支股票第 i 天的价格。

你最多可以完成 k 笔交易，一笔交易由一次买入和一次卖出组成。

注意：

  • 同一时间最多只能持有一支股票；
  • 必须先卖出当前持有的股票，才能再次买入；
  • 可以不进行任何交易。

请你计算最多可以获得的利润。

查看示例与约束

示例 1

text
输入：k = 2，prices = [2,4,1]
输出：2
解释：在价格为 2 时买入，在价格为 4 时卖出，利润为 2。

2
3

示例 2

text
输入：k = 2，prices = [3,2,6,5,0,3]
输出：7
解释：先在价格为 2 时买入、价格为 6 时卖出，获得利润 4；再在价格为 0 时买入、价格为 3 时卖出，获得利润 3，总利润为 7。

约束

  • 1 <= k <= 100
  • 1 <= prices.length <= 1000
  • 0 <= prices[i] <= 1000

2. 先理解题目 ​

先把“一笔交易”说清楚：一次买入和之后的一次卖出，合在一起才算一笔完整交易。买入后如果还没有卖出，这笔交易就还没有结束，也不能把账面变化当成最终利润。

所有操作必须遵守同一个顺序：

text
空仓 -> 买入 -> 持有股票 -> 卖出 -> 回到空仓
1

只有回到空仓后，才能开始下一笔交易。因此，连续买入两次、没有持股时卖出，或者第一笔还没卖出就开始第二笔，都是不合法的。

题目说的是“最多 k 笔”，而不是“必须 k 笔”。如果没有合适的机会，可以少做几笔，也可以一笔都不做，此时利润为 0。

一组合法方案的总利润，是每笔完整交易利润的总和：

text
总利润 = (第一次卖出价 - 第一次买入价)
        + (第二次卖出价 - 第二次买入价)
        + ...
1
2
3

例如 prices = [3, 8, 2, 9]：

  • 如果 k = 1，最多只能选一段完整的买卖过程，最优方案是价格 2 买入、价格 9 卖出，利润为 7；
  • 如果 k = 2，还可以先在价格 3 买入、价格 8 卖出，再在价格 2 买入、价格 9 卖出，总利润为 5 + 7 = 12。

所以，这道题要找的并不是某一个最大价差，而是：在时间顺序不交叉的前提下，最多选出 k 组“先买后卖”的区间，使它们的利润之和最大。理清这些约束后，下一步再考虑如何用状态表示它。

3. 定义状态与转移 ​

buy[j] 和 sell[j] 代表什么 ​

题目最多允许完成 k 笔交易。为了分别记录“最多 1 笔”、“最多 2 笔”直到“最多 k 笔”时的最优结果，我们用 j 表示当前允许的交易次数上限，范围是 1 ~ k。

因此，下标 j 不表示已经完成了第 j 笔交易，而是表示当前方案最多允许 j 笔交易。

对每个 j，维护两个状态：

状态含义
buy[j]处理到当前这一天，最多允许 j 笔交易且手里持有股票时，账户的最大余额
sell[j]处理到当前这一天，最多允许 j 笔交易且手里没有股票时，已经实现的最大利润

这里可以把买卖看成账户余额变化：

  • 买入股票：花钱，所以余额减少 price
  • 卖出股票：收钱，所以余额增加 price

buy[j] 和 sell[j] 可以理解为两个不断更新的最优记录：一个记录持股时的最大余额，另一个记录空仓时的最大利润。它们记录的是截至当前的最好结果，不是今天实际执行的操作。

初始化的值代表什么 ​

因为数组需要保留下标 0 作为边界状态，所以 buy 和 sell 的长度都是 k + 1：

js
const buy = new Array(k + 1).fill(-Infinity);
const sell = new Array(k + 1).fill(0);
1
2

初始化值的含义是：

  • buy[j] = -Infinity：还没有买入股票，所以持股状态不合法；
  • sell[j] = 0：什么都不做是合法方案，空仓利润为 0。

其中，下标 0 的含义是：

  • sell[0] = 0：最多允许 0 笔交易，当前空仓，利润为 0；
  • buy[0] = -Infinity：最多允许 0 笔交易时却持有股票，这是不合法的状态，后续转移也不会使用它。

sell[0] 会用于第一次买入的转移：还没有完成任何交易，就从利润 0 中减去买入价格。

状态转移代表什么 ​

状态转移包含两层遍历。

第一层：按天遍历所有价格

买入和卖出有明确的时间顺序，所以必须从第 0 天开始，按照 prices 的顺序逐天处理。在处理今天之前，buy 和 sell 保存的是前面所有天的最好结果；用今天的价格更新后，它们就变成了“处理到今天为止”的最好结果。

js
for (const price of prices) {
  // 用今天的价格更新所有状态
}
1
2
3

第二层：用今天的价格检查所有交易上限

对于同一个 price，需要检查 j = 1 ~ k 对应的 buy[j] 和 sell[j]。我们同时维护了“最多 1 笔”、“最多 2 笔”直到“最多 k 笔”时的最优结果，所以今天的价格要依次尝试更新每个持股和空仓记录。这是在比较候选状态，不表示今天同时执行了所有买卖操作。

更新 buy[j]

要得到“处理到今天后仍然持股”的最优结果，有两种方式：

  1. 今天不买，保留之前的最佳持股余额 buy[j]；
  2. 今天买入，从最多完成 j - 1 笔交易的空仓利润 sell[j - 1] 中减去买入价格。
js
buy[j] = Math.max(buy[j], sell[j - 1] - price);
1

更新 sell[j]

要得到“处理到今天后保持空仓”的最优结果，也有两种方式：

  1. 今天不卖，保留之前的最大空仓利润 sell[j]；
  2. 今天卖出，在之前的最佳持股余额 buy[j] 上加上卖出价格。
js
sell[j] = Math.max(sell[j], buy[j] + price);
1

这两个转移比较的是“今天不操作”和“今天执行一次操作”这两种到达方式，不是在比较今天的交易和之前的某笔交易。理解公式时，等号右侧都指今天价格更新前的最优值。

当 j < k 时，以更新 buy[j + 1] 为例：

js
buy[j + 1] = Math.max(buy[j + 1], sell[j] - price);
1

sell[j] 保存了前面最多完成 j 笔交易后的最大利润。用它减去今天的价格，就表示把之前积累的利润带到下一次买入中。

实际代码为什么倒序更新

完整代码会直接复用 buy 和 sell 数组。为了保证转移读取的仍然是今天更新前的值，j 需要从 k 遍历到 1，并先更新 sell[j]、再更新 buy[j]：

js
for (let j = k; j >= 1; j--) {
  sell[j] = Math.max(sell[j], buy[j] + price);
  buy[j] = Math.max(buy[j], sell[j - 1] - price);
}
1
2
3
4

倒序遍历时，更新 buy[j] 所需的 sell[j - 1] 还没有被今天的价格覆盖；先更新 sell[j] 则能保证它读取的 buy[j] 也是更新前的值。

如果改成从小到大遍历，在更新 buy[j + 1] 时，sell[j] 可能已经被今天的价格更新，就不再是上一天的状态。

每天都重复这个更新过程，所有价格处理完后，sell[j] 就表示最多允许 j 笔交易时的最大空仓利润。例如，sell[2] 会在不交易、只完成 1 笔交易或完成 2 笔交易的结果中取最大值。因此，题目的答案是 sell[k]。

不能取 buy[k]，因为它表示最后仍然持有股票，这笔交易还没有通过卖出完成。

4. 完整代码 ​

js
/**
 * 188. 买卖股票的最佳时机 IV
 * @param {number} k
 * @param {number[]} prices
 * @return {number}
 */
var maxProfit = function (k, prices) {
  const n = prices.length;
  if (n < 2 || k === 0) return 0;

  // n 天最多能完成 ⌊n / 2⌋ 笔交易，超出部分不会改变答案
  const maxTransactions = Math.min(k, Math.floor(n / 2));

  // 下标 j 表示最多允许 j 笔交易
  const buy = new Array(maxTransactions + 1).fill(-Infinity); // 持股时的最大余额
  const sell = new Array(maxTransactions + 1).fill(0); // 空仓时的最大利润

  for (const price of prices) {
    // 倒序且先更新 sell，保证等号右侧仍是今天更新前的状态
    for (let j = maxTransactions; j >= 1; j--) {
      sell[j] = Math.max(sell[j], buy[j] + price);
      buy[j] = Math.max(buy[j], sell[j - 1] - price);
    }
  }

  return sell[maxTransactions];
};

5. 最多两笔交易：前后缀分解 ​

当题目最多允许完成 2 笔交易时，也就是 123. 买卖股票的最佳时机 III，除了使用前面的通用状态机 DP，还可以从“分割点”的角度理解。

先看一个具体例子。对于 prices = [3, 8, 2, 9]，可以在价格 8 和价格 2 之间切开：

text
[3, 8] | [2, 9]
1
  • 左边最多做一笔交易：价格 3 买入、价格 8 卖出，利润为 5；
  • 右边最多做一笔交易：价格 2 买入、价格 9 卖出，利润为 7；
  • 两边的交易互不交叉，总利润为 5 + 7 = 12。

问题是，我们一开始不知道应该在哪里切。因此，需要尝试每个分割位置，并计算：

text
左边最多一笔交易的利润 + 右边最多一笔交易的利润
1

其中最大的结果，就是最多完成两笔交易时的最大利润。

left 和 right 表示什么 ​

用 i 表示分割位置，范围是 0 ~ n：

  • left[i]：前 i 天，也就是 prices[0..i-1] 中，最多完成一笔交易的最大利润；
  • right[i]：从第 i 天到最后，也就是 prices[i..n-1] 中，最多完成一笔交易的最大利润。

这样，分割位置 i 左右两边没有重叠：第一笔交易只能发生在左边，第二笔交易只能发生在右边。

下标 0 和 n 表示两个边界：

  • left[0] = 0：左边没有价格，不能交易；
  • right[n] = 0：右边没有价格，不能交易。

保留这两个边界，也就包含了只完成一笔交易或者完全不交易的情况。

怎么计算两个数组 ​

计算 left 时，从左向右遍历价格。不断记录前面出现过的最低价格 minPrice，再比较：

js
left[i + 1] = Math.max(
  left[i], // 今天不卖，保留前面的最大利润
  prices[i] - minPrice, // 今天卖出
);

right[i] = Math.max(
  right[i + 1], // 今天不买，保留后面的最大利润
  maxPrice - prices[i], // 今天买入
);

完整代码 ​

js
function maxProfit2(prices) {
  const n = prices.length;
  if (n < 2) return 0;

  // left[i]：前 i 天内，一笔交易的最大利润
  const left = new Array(n + 1).fill(0);
  let minPrice = prices[0];
  for (let i = 0; i < n; i++) {
    minPrice = Math.min(minPrice, prices[i]);
    left[i + 1] = Math.max(left[i], prices[i] - minPrice);
  }

  // right[i]：第 i 天到最后一天内，一笔交易的最大利润
  const right = new Array(n + 1).fill(0);
  let maxPrice = prices[n - 1];
  for (let i = n - 1; i >= 0; i--) {
    maxPrice = Math.max(maxPrice, prices[i]);
    right[i] = Math.max(right[i + 1], maxPrice - prices[i]);
  }

  // 尝试所有分割位置，取两边利润之和的最大值
  let maxProfit = 0;
  for (let i = 0; i <= n; i++) {
    maxProfit = Math.max(maxProfit, left[i] + right[i]);
  }

  return maxProfit;
}
