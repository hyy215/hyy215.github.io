二叉树 ​

AlgorithmTypeScript二叉树

二叉树由节点组成，每个节点最多有两个子节点，分别称为左子节点和右子节点。理解节点之间的引用关系后，创建、搜索和遍历二叉树，本质上都是沿着 left 和 right 访问节点。

本文先介绍如何使用 TypeScript 表示和创建二叉树，再实现二叉搜索树的搜索、插入和删除，说明二叉搜索树为什么可能退化、平衡树如何限制树高，最后实现前序、中序、后序和层序遍历。

二叉树是什么 ​

一棵二叉树可以为空；非空二叉树由根节点、左子树和右子树组成。左、右子树本身也都是二叉树。

常见术语包括：

  • 根节点：整棵树的起点，没有父节点；
  • 父节点：直接连接到下一层节点的节点；
  • 子节点：由父节点直接连接的节点；
  • 叶节点：没有子节点的节点；
  • 子树：以某个节点为根的树；
  • 深度：从根节点到当前节点经过的边数；
  • 高度：从当前节点到最深叶节点经过的边数。

下面是一棵二叉树：

text
        8
      /   \
     4     12
    / \    / \
   2   6  10  14

节点 8 是根节点，节点 2、6、10 和 14 是叶节点。节点 4 及其所有后代节点 2、6 组成一棵以节点 4 为根的子树，也是节点 8 的左子树。

再看深度和高度。按经过的边数计算，节点 4 的深度为 1，因为根节点 8 到它经过一条边；节点 4 的高度也为 1，因为它到最深叶节点同样经过一条边。

二叉树只限制每个节点最多有两个子节点，不要求节点值满足大小关系。二叉搜索树是在二叉树基础上增加了键值顺序约束。

TypeScript 如何表示和创建二叉树 ​

定义二叉树节点 ​

可以使用对象表示节点，并通过 left 和 right 保存左右子节点的引用：

ts
class TreeNode {
  val: number
  left: TreeNode | null
  right: TreeNode | null

  constructor(
    val: number,
    left: TreeNode | null = null,
    right: TreeNode | null = null
  ) {
    this.val = val
    this.left = left
    this.right = right
  }
}

从层序数组创建二叉树 ​

LeetCode 经常使用层序数组表示二叉树，null 表示对应位置没有节点：

text
[8, 4, 12, 2, 6, 10, 14]
1

可以使用队列将层序数组转换为节点结构：

ts
function arrayToBinaryTree(
  values: Array<number | null>
): TreeNode | null {
  const rootValue = values[0]

  if (rootValue === undefined || rootValue === null) {
    return null
  }

  const root = new TreeNode(rootValue)
  const queue: TreeNode[] = [root]

  let head = 0
  let index = 1

  // 同时检查父节点和值，避免数组中出现没有父节点承接的多余值
  while (head < queue.length && index < values.length) {
    const node = queue[head++]

    const leftValue = values[index++]
    if (leftValue !== undefined && leftValue !== null) {
      node.left = new TreeNode(leftValue)
      queue.push(node.left)
    }

    if (index >= values.length) break

    const rightValue = values[index++]
    if (rightValue !== undefined && rightValue !== null) {
      node.right = new TreeNode(rightValue)
      queue.push(node.right)
    }
  }

  return root
}

const root = arrayToBinaryTree([
  8, 4, 12, 2, 6, 10, 14
])

二叉搜索树 ​

二叉搜索树在二叉树基础上增加了顺序约束。对于树中的每个节点：

  • 左子树中的键值都小于当前节点；
  • 右子树中的键值都大于当前节点；
  • 左右子树也分别是二叉搜索树。

不同实现对重复值的处理方式可能不同。本文采用“忽略重复值”的策略。

前面的示例树就是一棵二叉搜索树：

     4     12

   2   6  10  14

搜索节点 ​

搜索时比较目标值和当前节点值：

  • 相等时返回当前节点；
  • 目标值较小时进入左子树；
  • 目标值较大时进入右子树。
ts
function searchBST(
  root: TreeNode | null,
  target: number
): TreeNode | null {
  let current = root

  while (current) {
    if (target === current.val) {
      return current
    }

    current = target < current.val
      ? current.left
      : current.right
  }

  return null
}

插入节点 ​

插入过程与搜索类似。找到空位置后创建新节点：

ts
function insertBST(
  root: TreeNode | null,
  value: number
): TreeNode {
  if (!root) {
    return new TreeNode(value)
  }

  let current = root

  while (true) {
    if (value === current.val) {
      return root
    }

    if (value < current.val) {
      if (!current.left) {
        current.left = new TreeNode(value)
        return root
      }

      current = current.left
    } else {
      if (!current.right) {
        current.right = new TreeNode(value)
        return root
      }

      current = current.right
    }
  }
}

删除节点 ​

删除时先按照二叉搜索树的规则找到目标节点，再根据它的子节点情况处理：

  • 没有左子节点：用右子树接替目标节点，删除叶节点也属于这种情况；
  • 没有右子节点：用左子树接替目标节点；
  • 左右子节点都存在：找到右子树中的最小节点，也就是目标节点的后继；用后继值替换目标节点的值，再从右子树中删除后继。

后继是右子树中的最小节点，因此它一定没有左子节点。删除后继时，问题会转化为前两种情况之一。

ts
function deleteBST(
  root: TreeNode | null,
  value: number
): TreeNode | null {
  if (!root) {
    return null
  }

  // 目标值较小时，继续在左子树中删除
  if (value < root.val) {
    root.left = deleteBST(root.left, value)
    return root
  }

  // 目标值较大时，继续在右子树中删除
  if (value > root.val) {
    root.right = deleteBST(root.right, value)
    return root
  }

  // 没有左子节点时，右子树直接接替当前节点
  if (!root.left) {
    return root.right
  }

  // 没有右子节点时，左子树直接接替当前节点
  if (!root.right) {
    return root.left
  }

  // 左右子节点都存在，寻找右子树中的最小节点
  let successor = root.right
  while (successor.left) {
    successor = successor.left
  }

  // 使用后继值替换当前值，再删除右子树中重复的后继值
  root.val = successor.val
  root.right = deleteBST(root.right, successor.val)

  return root
}

删除根节点时，整棵树的根可能发生变化，因此调用方需要接收函数返回值：

ts
const newRoot = deleteBST(root, 8)
1

搜索和插入最多沿一条根到叶的路径访问节点。删除除了查找目标节点，在目标节点有两个子节点时还需要继续查找并删除后继；这些操作经过的节点数仍然与树高成正比。设树高为 h，搜索、插入和删除的时间复杂度都是 O(h)。

当树形较均衡时，h 为 O(log n)；如果节点接近一条链，h 会增长到 O(n)。

此时二叉搜索树退化成了链表。搜索、插入和删除都可能需要逐个经过节点，时间复杂度由 O(log n) 退化为 O(n)。

平衡树通过额外约束控制树高。在插入或删除破坏约束后，树可以通过旋转等操作重新调整结构。不同平衡树采用的约束并不相同，因此不能把某一种平衡条件当成所有平衡树的统一定义。

AVL 树 ​

AVL 树是一种平衡二叉搜索树。对树中的每个节点，其左右子树的高度差不超过 1。

插入或删除节点后，如果高度差不再满足要求，可以通过左旋、右旋或组合旋转恢复平衡。AVL 树的搜索、插入和删除复杂度都是 O(log n)。

红黑树 ​

红黑树为节点增加红色或黑色标记，并通过一组颜色约束限制树高。包含 n 个内部节点的红黑树，高度不超过 2log₂(n + 1)，因此搜索、插入和删除都能保持 O(log n) 的时间复杂度。

红黑树的平衡约束与 AVL 树不同，不能使用“左右子树高度差不超过 1”来定义红黑树。

AVL 与红黑树如何选择 ​

两者都能保证搜索、插入和删除为 O(log n)，主要差异如下：

对比项AVL 树红黑树
最坏高度约 1.4404 log₂ n + O(1)不超过 2 log₂(n + 1)
平衡辅助信息节点高度或平衡状态节点颜色
插入旋转最多 2 次最多 2 次
删除旋转最坏 O(log n) 次最多 3 次

表中的高度按根到最深叶节点路径的边数计算；如果按路径上的节点数计算，高度上界需要加 1。

选择时可以重点考虑更新频率：

  • 查询明显多于更新：AVL 树的高度限制更严格，最坏查询路径更短；
  • 删除操作频繁：红黑树的平衡条件更宽松，删除所需的旋转次数上界更小；
  • 需要有序遍历和最坏复杂度保证：两者都适合，具体选择还要结合已有容器和实现成本。

具体实现可参考《AVL 树：旋转与再平衡》与《红黑树：颜色约束、旋转与修复》。

遍历是按照某种顺序访问树中的所有节点。下面继续使用同一棵树：

前序、中序和后序遍历属于深度优先遍历；层序遍历属于广度优先遍历。

前序遍历 ​

前序遍历的顺序是：

text
根节点 → 左子树 → 右子树
1

示例树的遍历结果为：

text
8, 4, 2, 6, 12, 10, 14
1
ts
function preorderTraversal(
  root: TreeNode | null
): number[] {
  const result: number[] = []

  function traverse(node: TreeNode | null): void {
    if (!node) return

    result.push(node.val)
    traverse(node.left)
    traverse(node.right)
  }

  traverse(root)
  return result
}

层序遍历 ​

层序遍历从根节点开始，按深度递增、每层从左到右访问节点。

示例树的遍历结果为：

text
8, 4, 12, 2, 6, 10, 14
1

可以使用队列实现：

ts
function levelOrderTraversal(
  root: TreeNode | null
): number[] {
  if (!root) return []

  const result: number[] = []
  const queue: TreeNode[] = [root]

  let head = 0

  while (head < queue.length) {
    const node = queue[head++]

    result.push(node.val)

    if (node.left) {
      queue.push(node.left)
    }

    if (node.right) {
      queue.push(node.right)
    }
  }

  return result
}
