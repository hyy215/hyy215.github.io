双指针算法 ​

Algorithm双指针

什么是双指针 ​

双指针不是某一种固定的代码模板，而是一类通过两个位置协同移动来缩小问题范围的算法方法。两个指针可以是数组下标、字符串位置或链表节点引用，分别用于读取、写入、维护边界或保持距离。

每次比较或计算后，算法根据当前状态移动其中一个或两个指针，同时排除已经处理或不可能产生答案的部分。

用两个位置共同维护一个不变量，并通过有依据的移动逐步缩小尚未处理的范围。

关键不在于代码里是否出现两个变量，而在于能否说明两个指针的职责、共同维护的不变量，以及移动指针不会遗漏答案的原因。

案例：删除有序数组中的重复项 ​

题目：26. 删除有序数组中的重复项 ​

给定一个按非递减顺序排列的整数数组 nums。请在数组原有存储空间内完成去重，使每个不同的元素只保留一次，并返回去重后的元素个数 k。

完成后，nums[0..k-1] 应按原顺序保存所有不同元素；下标 k 之后的内容不参与判题，可以忽略。

判题时只会比较返回值 k 和 nums 的前 k 个元素，其余位置可为任意值。

约束

  • 1 <= nums.length <= 3 * 10^4
  • -100 <= nums[i] <= 100
  • nums 已按非递减顺序排列

解题思路 ​

数组已经有序，因此相同元素一定相邻。可以使用同向快慢指针维护去重后的有效前缀：

  • 慢指针 slow：指向已去重区间的最后一个元素，nums[0..slow] 始终保存已经发现的不同元素；
  • 快指针 fast：从下标 1 开始向后扫描，寻找下一个不同元素。

当 nums[fast] === nums[slow] 时，当前元素重复，继续移动快指针；否则先执行 slow++，再将 nums[fast] 写入 nums[slow]，扩展已去重区间。

扫描结束后，nums[0..slow] 就是有效前缀，元素个数为 slow + 1。数组为空或只有一个元素时，直接返回其长度。

TypeScript 实现 ​

ts
function removeDuplicates(nums: number[]): number {
  if (nums.length <= 1) {
    return nums.length;
  }

  let slow = 0;

  for (let fast = 1; fast < nums.length; fast++) {
    if (nums[fast] !== nums[slow]) {
      slow++;
      nums[slow] = nums[fast];
    }
  }

  return slow + 1;
}

复杂度分析 ​

快指针从下标 1 扫描到数组末尾，每个元素最多读取一次，因此时间复杂度为 O(n)。

算法只使用了 slow、fast 等常数个变量，并直接修改输入数组，因此额外空间复杂度为 O(1)。
