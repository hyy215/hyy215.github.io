加油站（Gas Station） ​

Algorithm贪心

「加油站」的经典做法是贪心一次遍历：走到哪里没油了，之前所有起点一票否决，直接从下一站重新出发。

例题：134. 加油站 ​

环形路上有 n 个加油站，第 i 个站有 gas[i] 升汽油。从 i 到下一站需要消耗 cost[i] 升汽油，油箱容量无限。从某站出发（初始油量为 0），求能跑完一圈的起始站下标；无解返回 -1。

查看示例与约束

示例 1

text
输入：gas = [1,2,3,4,5]，cost = [3,4,5,1,2]
输出：3
解释：从 3 号站出发时依次经过 3 → 4 → 0 → 1 → 2 → 3，每段行程前的油量都足够支付下一段消耗，最终恰好回到起点。

示例 2

输入：gas = [2,3,4]，cost = [3,4,3]
输出：-1
解释：从 0 号或 1 号站出发时连下一站都无法到达；从 2 号站出发虽能到达 0 号和 1 号站，但随后油量不足以返回 2 号站，因此不存在合法起点。
1
2
3

约束

  • n == gas.length == cost.length
  • 1 <= n <= 10^5
  • 0 <= gas[i], cost[i] <= 10^4
  • 如果存在解，保证它是唯一的

思路 ​

把问题想象成：开车跑一圈，每站能加油也要消耗油，找一个能跑完全程的出发点。

模拟过程

从第 0 站出发，一路往前走，记录当前剩余油量 tank：

  • 每到一站：tank += gas[i] - cost[i]（加油减消耗）
  • 如果 tank < 0，说明从当前起点走到这里撑不住了

关键问题：tank < 0 时，为什么可以直接跳过所有走过的站？

假设当前起点是 start，在第 i 站出现 tank < 0。对于 start 到 i 之间的任意一站 j：

  • 从 start 到 j - 1 的累计油量非负，否则算法会在到达 i 之前重置起点
  • 从 start 到 i 的累计净油量为负

因此，从 j 到 i 的累计净油量等于“start 到 i 的累计净油量”减去“start 到 j - 1 的累计净油量”，结果一定为负。从 j 以 0 油量重新出发，同样无法通过第 i 站。

所以 start 到 i 之间的所有站都可以排除，下一次直接从 i + 1 出发。

总量够用时，最后留下的起点为什么合法？

每次出现 tank < 0，从当前 start 到 i 的总油量变化都是负数。可以把这段路看成一个“亏损段”：它自己提供的油不够跑完，需要从前面带一些油进来。

算法遇到亏损段就从 i + 1 重新出发。遍历结束后，整条路线被分成若干个亏损段，以及最后一个没有触发 tank < 0 的“结余段”。

以示例 1 为例，每站的油量变化是：

txt
站点          [0]  |  [1]  |  [2]  |   [3, 4]
油量变化      [-2] |  [-2] |  [-2] |  [+3, +3]
分段类型      亏损段 | 亏损段 | 亏损段 |   结余段
1
2
3

前三个站各缺 2 升油，最后两个站一共能结余 6 升油。于是从第 3 站出发，先攒下 6 升油，再绕回前面填补三个亏损段：

txt
经过站点          3    4    0    1    2
油箱剩余          3    6    4    2    0
1
2

为什么这种分段方式对一般情况也成立？

  • 最后的结余段没有触发 tank < 0，所以从最终的 start 出发一定能先走到数组末尾，并留下非负油量
  • 每个亏损段都是在最后一步才首次让 tank 变成负数，此前的过程都不缺油。因此，只要进入这段之前带的油足以填平整段的缺口，就能安全通过
  • 如果 sum(gas) >= sum(cost)，说明结余段攒下的油足以填平前面所有亏损段的缺口

因此，从最终的 start 出发，先在结余段攒油，再绕回数组开头依次通过各个亏损段，就能完成一圈。

  • 如果 sum(gas) < sum(cost)，整圈得到的油不够消耗，从哪里出发都无解
  • 如果 sum(gas) >= sum(cost)，算法留下的 start 就是一个合法起点

至于答案唯一，则来自题目的输入保证，而不是总量条件本身。

时间复杂度 O(n)，只遍历一次；额外空间 O(1)。

代码（JavaScript） ​

js
var canCompleteCircuit = function (gas, cost) {
  let totalTank = 0; // 全程总净收益，用于判断是否有解
  let tank = 0;      // 从当前 start 出发的累计剩余油量
  let start = 0;

  for (let i = 0; i < gas.length; i++) {
    const net = gas[i] - cost[i];
    totalTank += net;
    tank += net;

    // 油量不足，当前起点到 i 之间全部排除，起点后移
    if (tank < 0) {
      start = i + 1;
      tank = 0;
    }
  }

  return totalTank >= 0 ? start : -1;
};
