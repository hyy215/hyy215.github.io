堆与优先队列 ​

Algorithm堆优先队列

堆适合解决“不断取出当前最大值或最小值”的问题。LeetCode 中常见的考法包括：第 K 大、前 K 个高频元素和合并多个有序序列。

一、核心概念 ​

优先队列是一种抽象数据类型，具有以下特点：

  • 出队顺序：元素按照优先级出队，而不是按照进入队列的先后顺序出队。
  • 核心能力：快速访问或移除当前优先级最高的元素。
  • 有序性：只保证队首元素的优先级最高，不保证所有元素整体有序。

二叉堆是优先队列的常见实现。本文所说的“堆”特指二叉堆：它的逻辑结构是一棵完全二叉树，通常使用数组存储，并满足堆序性质。

  • 小顶堆：父节点不大于子节点，堆顶是最小值。
  • 大顶堆：父节点不小于子节点，堆顶是最大值。
  • 插入元素：放到数组末尾，再向上调整，时间复杂度 O(log n)。
  • 删除堆顶：用末尾元素覆盖堆顶，再向下调整，时间复杂度 O(log n)。
  • 查看堆顶：时间复杂度 O(1)。
  • 建堆：从最后一个非叶子节点开始向下调整，时间复杂度 O(n)。

父节点：(i - 1) >> 1
左子节点：2 * i + 1
右子节点：2 * i + 2

二、通用堆实现 ​

不同题目对“优先级最高”的定义不同：可能是数值最小、出现频率最低，也可能是链表节点值最小。下面通过比较器定义优先级，实现一个可以直接复用的通用堆；当 compare(a, b) <= 0 时，a 的优先级不低于 b。

ts
class Heap<T> {
  private heap: T[] = [];

  /**
   * 创建堆。
   * compare(a, b) <= 0 表示 a 的优先级不低于 b。
   */
  constructor(private readonly compare: (a: T, b: T) => number) {}

  /** 返回堆中的元素数量。 */
  get size(): number {
    return this.heap.length;
  }

  /** 返回堆顶元素；堆为空时返回 undefined。 */
  peek(): T | undefined {
    return this.heap[0];
  }

  /** 返回堆数组的副本，元素不保证整体有序。 */
  toArray(): T[] {
    return [...this.heap];
  }

  /** 插入元素，并通过向上调整恢复堆序。 */
  push(value: T): void {
    this.heap.push(value);
    this.siftUp(this.heap.length - 1);
  }

  /** 移除并返回堆顶元素；堆为空时返回 undefined。 */
  pop(): T | undefined {
    if (this.heap.length === 0) return undefined;
    if (this.heap.length === 1) return this.heap.pop();

    const top = this.heap[0];
    this.heap[0] = this.heap.pop()!;
    this.siftDown(0);
    return top;
  }

  /**
   * 将指定位置的元素向上调整到满足堆序的位置。
   * 通常在元素插入数组末尾后调用：反复比较当前节点与父节点，
   * 如果当前节点的优先级更高就交换，直到到达根节点，
   * 或父节点的优先级已经不低于当前节点。
   */
  private siftUp(index: number): void {
    while (index > 0) {
      const parent = (index - 1) >> 1;
      if (this.compare(this.heap[parent], this.heap[index]) <= 0) break;

      [this.heap[parent], this.heap[index]] = [this.heap[index], this.heap[parent]];
      index = parent;
    }
  }

  /**
   * 将指定位置的元素向下调整到满足堆序的位置。
   * 通常在末尾元素覆盖堆顶后调用：比较当前节点和两个子节点，
   * 选出优先级最高的节点；如果最高优先级节点不是当前节点，
   * 就交换并继续向下，直到当前节点已经满足堆序或到达叶子节点。
   */
  private siftDown(index: number): void {
    const length = this.heap.length;

    while (true) {
      const left = index * 2 + 1;
      const right = left + 1;

      // 暂时认为当前节点的优先级最高。
      let best = index;

      // 如果左子节点存在且优先级更高，就记录左子节点。
      if (left < length && this.compare(this.heap[left], this.heap[best]) < 0) {
        best = left;
      }

      // 如果右子节点存在且优先级更高，就记录右子节点。
      if (right < length && this.compare(this.heap[right], this.heap[best]) < 0) {
        best = right;
      }

      // 当前节点已经是三者中优先级最高的，不需要继续调整。
      if (best === index) break;

      // 与优先级更高的子节点交换，然后从新位置继续向下检查。
      [this.heap[index], this.heap[best]] = [this.heap[best], this.heap[index]];
      index = best;
    }
  }
}

三、经典题目 ​

1. 215. 数组中的第 K 个最大元素 ​

给定整数数组 nums 和整数 k，返回数组排序后的第 k 大元素，而不是第 k 个不同的元素。原题要求设计期望时间复杂度为 O(n) 的算法；下面的小顶堆解法是便于理解堆的替代方案，时间复杂度为 O(n log k)。

查看示例与约束

示例 1

text
输入：nums = [3,2,1,5,6,4]，k = 2
输出：5
1
2

示例 2

text
输入：nums = [3,2,3,1,2,4,5,5,6]，k = 4
输出：4
1
2

约束

  • 1 <= k <= nums.length <= 10^5
  • -10^4 <= nums[i] <= 10^4

维护一个容量为 k 的小顶堆：

  • 遍历数组，将元素放入堆中。
  • 堆大小超过 k 时，删除堆顶最小值。
  • 遍历结束后，堆中保留最大的 k 个元素，堆顶就是第 k 大。

时间复杂度 O(n log k)，空间复杂度 O(k)。

ts
function findKthLargest(nums: number[], k: number): number {
  const heap = new Heap<number>((a, b) => a - b);

  for (const num of nums) {
    heap.push(num);
    if (heap.size > k) heap.pop();
  }

  return heap.peek()!;
}

2. 347. 前 K 个高频元素 ​

给定整数数组 nums 和整数 k，返回出现频率最高的 k 个元素，返回顺序任意。题目保证前 k 高频元素的集合唯一。

约束

  • 1 <= nums.length <= 10^5
  • -10^4 <= nums[i] <= 10^4
  • 1 <= k <= nums 中不同元素的数量
  • 题目保证前 k 个高频元素的集合唯一

原题进阶要求算法优于 O(n log n)。

先用哈希表统计频率，再维护一个容量为 k 的小顶堆。堆中比较的不是数字大小，而是出现频率。

ts
function topKFrequent(nums: number[], k: number): number[] {
  const frequency = new Map<number, number>();
  for (const num of nums) {
    frequency.set(num, (frequency.get(num) ?? 0) + 1);
  }

  const heap = new Heap<[number, number]>((a, b) => a[1] - b[1]);

  for (const entry of frequency) {
    heap.push(entry);
    if (heap.size > k) heap.pop();
  }

  return heap.toArray().map(([num]) => num);
}

3. 23. 合并 K 个升序链表 ​

输出：[]

约束

  • k == lists.length
  • 0 <= k <= 10^4
  • 0 <= lists[i].length <= 500
  • -10^4 <= lists[i][j] <= 10^4
  • 每条链表均按升序排列
  • 全部链表的节点总数不超过 10^4

把每条链表的头节点放入小顶堆，每次取出值最小的节点接到结果链表后面，再把该节点的下一个节点放入堆。

堆中最多有 k 个节点。设所有链表共有 n 个节点，时间复杂度 O(n log k)，空间复杂度 O(k)。

下面的 ListNode 类型和构造函数由 LeetCode 运行环境提供。

ts
function mergeKLists(lists: Array<ListNode | null>): ListNode | null {
  const heap = new Heap<ListNode>((a, b) => a.val - b.val);

  for (const node of lists) {
    if (node) heap.push(node);
  }

  const dummy = new ListNode(0);
  let current = dummy;

  while (heap.size) {
    const node = heap.pop()!;
    current.next = node;
    current = node;
    if (node.next) heap.push(node.next);
  }

  return dummy.next;
}

四、怎么判断一道题适合用堆 ​

看到以下描述时，可以优先考虑堆：

  • 求第 k 大、第 k 小。
  • 求最大的 k 个或最小的 k 个元素。
  • 数据持续进入，需要动态获取最大值或最小值。
  • 合并多个有序序列。
  • 每次都要从候选集合中取出当前最优元素。

需要注意：堆只能保证堆顶元素最优，不能保证整个数组有序。如果题目需要完整有序结果，通常还需要持续出堆或直接排序。
