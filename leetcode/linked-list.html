链表 ​

AlgorithmJavaScript链表归并排序

链表由一组节点组成，每个节点保存自身的数据，以及指向下一个节点的引用。理解这种引用关系后，遍历、插入、删除和反转链表都会变成对 next 的读取或修改。

本文先介绍如何在 JavaScript 中表示和创建单链表，再以 206. 反转链表 为例，通过迭代和递归两种写法理解如何重新连接节点，最后通过 148. 排序链表 理解归并排序在链表中的应用。

链表是什么 ​

单链表中的每个节点包含两部分：

  • val：当前节点保存的数据；
  • next：下一个节点的引用，尾节点的 next 为 null。

一条包含 1、2、3 的链表可以表示为：

text
head = [val: 1] → [val: 2] → [val: 3] → null
1

head 保存第一个节点的引用。从 head 开始不断读取 next，就能依次访问整条链表。与数组不同，单链表不能根据下标直接访问任意节点，只能从头节点开始逐个向后遍历。

JavaScript 如何表示链表 ​

JavaScript 使用对象表示节点，使用对象引用连接节点。

下面定义链表节点：

ts
class ListNode {
  val: number
  next: ListNode | null

  constructor(val: number, next: ListNode | null = null) {
    this.val = val
    this.next = next
  }
}

function arrayToLinkedList(values: number[]): ListNode | null {
  const dummy = new ListNode(0)
  let tail = dummy

  for (const value of values) {
    tail.next = new ListNode(value)
    tail = tail.next
  }

  return dummy.next
}

206. 反转链表 ​

反转链表不是交换节点中的值，而是让每个节点的 next 改为指向原来的前一个节点：

text
反转前：1 → 2 → 3 → 4 → 5 → null
反转后：5 → 4 → 3 → 2 → 1 → null
1
2

进阶： 链表既可以迭代反转，也可以递归反转。你能实现这两种方法吗？

方案一：迭代（三指针） ​

思路 ​

维护三个节点引用：

  • prev：已反转部分的头节点，初始为 null；
  • curr：当前待处理节点，初始为 head；
  • next：暂存 curr.next，防止修改引用后丢失剩余链表。

每轮循环依次执行“保存后继 → 反转引用 → 整体前移”：

text
初始：
prev = null
curr = 1 → 2 → 3 → null

处理节点 1 后：
prev = 1 → null
curr = 2 → 3 → null

处理节点 2 后：
prev = 2 → 1 → null
curr = 3 → null

处理节点 3 后：
prev = 3 → 2 → 1 → null
curr = null

循环结束时，curr 已经越过原尾节点，prev 引用新的头节点。

代码（TypeScript） ​

ts
function reverseList(head: ListNode | null): ListNode | null {
  let prev: ListNode | null = null
  let curr = head

  while (curr) {
    const next = curr.next   // 1. 保存后继
    curr.next = prev         // 2. 反转当前引用
    prev = curr              // 3. prev 和 curr 向后移动
    curr = next
  }

  return prev
}

每个节点只处理一次，时间复杂度为 O(n)；除三个节点引用外不需要随链表长度增长的额外空间，因此额外空间复杂度为 O(1)。

易错点 ​

  • 必须先保存 curr.next，再执行 curr.next = prev，否则会丢失尚未处理的链表；
  • 循环结束后，prev 才是新的头节点，curr 已经是 null；
  • 反转的是节点之间的引用，不需要交换节点的 val。

方案二：递归 ​

思路 ​

递归写法先反转 head.next 开始的子链表，再在回溯时让后继节点指回当前节点。

代码（TypeScript） ​

ts
function reverseListRecursive(head: ListNode | null): ListNode | null {
  // 空链表或单节点已经是反转结果
  if (!head || !head.next) return head

  const next = head.next
  const newHead = reverseListRecursive(next)

  next.next = head   // 后继节点指回当前节点
  head.next = null   // 断开当前节点原来的 next
  return newHead
}

以 1 → 2 → 3 → null 为例，递归过程分为向下调用和回溯两部分：

  1. 递归沿着 next 向下调用，直到尾节点：

    text
    reverseList(1 → 2 → 3)
  → reverseList(2 → 3)
    → reverseList(3)，返回节点 3
    1
    2
    3

  2. 回到节点 2 所在的递归层，此时 head 是节点 2，next 是节点 3：

    • next.next = head：让节点 3 指向节点 2；
    • head.next = null：断开节点 2 原来指向节点 3 的引用；
    • 链表变为 3 → 2 → null，继续返回头节点 3。

  3. 回到节点 1 所在的递归层，此时 head 是节点 1，next 是节点 2：

    • next.next = head：让节点 2 指向节点 1；
    • head.next = null：断开节点 1 原来指向节点 2 的引用；
    • 链表最终变为 3 → 2 → 1 → null，返回的头节点始终是节点 3。

每个节点同样只处理一次，时间复杂度为 O(n)。递归深度为 O(n)，调用栈占用的额外空间也是 O(n)。

JavaScript 运行环境允许的递归深度有限，链表过长时可能出现调用栈溢出。因此在输入规模较大或规模未知时，应优先使用迭代方案。

理解要点 ​

  • newHead 始终引用原链表的尾节点，也就是反转后的头节点；
  • 执行 next.next = head 后，必须再把 head.next 设为 null，否则相邻节点会互相引用并形成环。

  • -10^5 <= Node.val <= 10^5

进阶： 在 O(n log n) 时间复杂度和常数级空间复杂度下，对链表进行排序。

为什么选归并排序 ​

链表不支持随机访问，不适合直接套用基于数组下标的堆排序或原地快速排序。归并排序则天然适合链表：

  • 合并两个有序链表只需修改指针，无需额外数组，可做到 O(1) 额外空间；
  • 无论输入是否有序，时间复杂度稳定为 O(n log n)；
  • 是稳定排序。

归并排序的通用原理及自顶向下、自底向上两种实现方式，参见归并排序。下面只讨论链表场景下的具体实现。

方案一：自顶向下（递归） ​

用快慢指针找到链表中点，断开为两半，递归排序后合并。

js
var sortList = function(head) {
    if (!head || !head.next) return head;

    // 快慢指针找中点，prev 记录 slow 的前一个节点
    let slow = head, fast = head, prev = null;
    while (fast && fast.next) {
        prev = slow;
        slow = slow.next;
        fast = fast.next.next;
    }
    prev.next = null; // 从中点断开

    const left  = sortList(head);
    const right = sortList(slow);
    return merge(left, right);
};

function merge(l1, l2) {
    const dummy = { next: null };
    let cur = dummy;
    while (l1 && l2) {
        if (l1.val <= l2.val) { cur.next = l1; l1 = l1.next; }
        else                  { cur.next = l2; l2 = l2.next; }
        cur = cur.next;
    }
    cur.next = l1 || l2;
    return dummy.next;
}

合并两个有序链表本身只需要常数个指针，额外空间为 O(1)；但自顶向下方案需要递归地将链表不断二分，最大递归深度为 O(log n)。每层调用都要在调用栈中保存局部变量和返回位置，因此整体额外空间复杂度为 O(log n)，不满足进阶要求的 O(1) 空间。

这里的递归也不是尾递归：左右链表排序完成后还要执行 merge，所以通常无法通过尾调用优化消除调用栈。

方案二：自底向上（迭代）✅ 满足进阶 ​

核心思路 ​

跳过拆分，直接从最底层开始：

  1. 先算出链表长度 n；
  2. 用一个变量 subLen，从 1 开始，每轮 翻倍（subLen <<= 1），直到 subLen >= n；
  3. 每一轮中，把链表按 subLen 切成若干段，相邻两段两两归并，再拼回链表；
  4. 共执行 log₂n 轮，每轮遍历链表一次，总时间 O(n log n)，全程只用常数个指针，空间 O(1)。

以 4 → 2 → 1 → 3 → 8 → 6 → 5 → 7 为例：

初始：           4 → 2 → 1 → 3 → 8 → 6 → 5 → 7

第 1 轮 subLen=1：[4][2]  [1][3]  [8][6]  [5][7]
  归并后：        2 → 4 | 1 → 3 | 6 → 8 | 5 → 7

第 2 轮 subLen=2：[2,4][1,3]  [6,8][5,7]
  归并后：        1 → 2 → 3 → 4 | 5 → 6 → 7 → 8

第 3 轮 subLen=4：[1,2,3,4][5,6,7,8]
  归并后：        1 → 2 → 3 → 4 → 5 → 6 → 7 → 8  ✓

cut(head, n) 函数详解 ​

每轮需要从链表里精确切出长度为 subLen 的一段，cut 承担这个职责： 从 head 走 n 步，在第 n 个节点处断开链表，返回 [切点节点, 下一段头节点]。

初始 cur：4 → 2 → 1 → 3 → ...

head1 = cur                    →  4 → 2 → 1 → 3 → ...（完整链表）
[tail1, head2] = cut(head1, 1) →  tail1 = [4], head2 = 2 → 1 → 3 → ...
[tail2, rest]  = cut(head2, 1) →  tail2 = [2], rest  = 1 → 3 → ...

此时：
  head1 = [4]（null 结尾）   ← 左半段
  head2 = [2]（null 结尾）   ← 右半段
  cur   = 1 → 3 → ...        ← 剩余，下次循环用

cut 通过把第 n 个节点的 next 设为 null，将子段从链表上物理断开：

js
/**
 * 从 head 起走 n 步，在第 n 个节点处切断链表
 * @param {ListNode} head
 * @param {number} n
 * @returns {[ListNode|null, ListNode|null]} [切点节点, 下一段头节点]
 */
function cut(head, n) {
    while (--n && head) {
        head = head.next;
    }
    if (head === null) {
        return [null, null];
    }
    const rest = head.next;
    head.next = null;       // 断开
    return [head, rest];    // [切点节点, 下一段头]
}

返回切点节点（而非只返回下一段头），可以将它作为子链表的尾节点传给 merge，避免合并后再次遍历链表寻找尾节点。

完整代码 ​

js
var sortList = function(head) {
    let len = 0, node = head;
    while (node) { len++; node = node.next; }

    const dummy = { next: head };

    for (let subLen = 1; subLen < len; subLen <<= 1) {
        let prev = dummy;
        let cur  = dummy.next;

        while (cur) {
            const head1 = cur;
            const [tail1, head2] = cut(head1, subLen);
            const [tail2, rest]  = cut(head2, subLen);
            cur = rest;

            const [merged, tail] = merge(head1, head2, tail1, tail2);
            prev.next = merged;
            prev = tail;
        }
    }

    return dummy.next;
};

function cut(head, n) {
    while (--n && head) head = head.next;
    if (head === null) return [null, null];
    const rest = head.next;
    head.next = null;
    return [head, rest];
}

function merge(l1, l2, tail1, tail2) {
    const dummy = { next: null };
    let tail = dummy;

    while (l1 && l2) {
        if (l1.val <= l2.val) {
            tail.next = l1;
            l1 = l1.next;
        } else {
            tail.next = l2;
            l2 = l2.next;
        }
        tail = tail.next;
    }

    if (l1) {
        tail.next = l1;
        tail = tail1;
    } else if (l2) {
        tail.next = l2;
        tail = tail2;
    }

    return [dummy.next, tail];
}
