Kadane 算法 ​

Algorithm动态规划贪心视角

Kadane 算法用于在线性时间内求一个数组的最大连续子数组和。它在遍历数组时持续回答两个问题：

  • 以当前位置结尾的子数组，最大和是多少？
  • 截至当前位置，整个数组中出现过的最大子数组和是多少？

只要维护这两个值，就不需要枚举所有子数组。

算法介绍 ​

遍历到 nums[i] 时，以当前位置结尾的最优子数组只有两种选择：

  1. 接在以前一位置结尾的最优子数组后面；
  2. 舍弃前面的元素，从 nums[i] 重新开始。

Kadane 算法在每个位置选择两者中的较大值，同时更新全局最大值。整个过程只扫描数组一次，因此时间复杂度为 O(n)；只维护当前状态时，额外空间为 O(1)。

常见解题方法 ​

动态规划 ​

令 dp[i] 表示必须以位置 i 结尾的最大子数组和。由于子数组不能为空，初始状态为：

dp[0] = nums[0]

对于后续位置，状态转移为：

dp[i] = max(dp[i - 1] + nums[i], nums[i])

最终答案是所有 dp[i] 中的最大值。

贪心视角 ​

同一个状态转移也可以从贪心角度理解：

  • 如果 dp[i - 1] > 0，前面的子数组能为当前结果带来正收益，继续连接；
  • 如果 dp[i - 1] <= 0，保留前面的子数组不会使结果变大，从 nums[i] 重新开始。

这里的贪心选择并不是另一套算法，而是对动态规划转移的等价解释。

空间压缩 ​

计算 dp[i] 时只依赖 dp[i - 1]，因此不必保存整个 dp 数组。常见实现使用：

  • currentMax：以当前位置结尾的最大子数组和；
  • maxSum：遍历到当前位置时的全局最大子数组和。

这种动态规划的空间压缩实现通常就是所说的 Kadane 算法。

例题：53. 最大子数组和 ​

给你一个整数数组 nums，找出和最大的连续子数组（至少包含一个元素），返回其最大和。

这里的子数组必须由原数组中一段连续元素组成，不能跳过中间元素。

约束

  • 1 <= nums.length <= 10^5
  • -10^4 <= nums[i] <= 10^4

原题进阶问题还要求：在已经掌握 O(n) 解法后，尝试用分治法求解。

代码（TypeScript） ​

ts
function maxSubArray(nums: number[]): number {
  let maxSum = nums[0];
  let currentMax = nums[0];

  for (let i = 1; i < nums.length; i++) {
    currentMax = Math.max(currentMax + nums[i], nums[i]);
    maxSum = Math.max(maxSum, currentMax);
  }

  return maxSum;
}
