无重叠区间与引爆气球：按右端点排序的区间贪心 ​

Algorithm贪心区间

公共解题思路 ​

这两题看起来一个在删除区间，一个在射气球，但处理方式很接近：都希望当前选择尽量少影响后面的区间。

遇到这类区间选择或覆盖问题，可以先把区间按右端点从小到大排好。排在最前面的区间最早结束，也是最先需要做决定的区间。先围绕它确定当前的贪心选择，再继续扫描后面的区间。

排序后，从左到右扫描区间，并维护最近一次贪心选择确定的右端点：

  • 如果当前区间不需要产生新的选择，就继续检查下一个区间。
  • 如果需要产生新的选择，就增加计数，并把当前区间的右端点作为新的边界。

两道题的整体框架相同，区别主要在于：什么情况下需要产生新的选择，以及最终统计的是保留区间数、删除区间数还是箭数。这些条件放到具体题目中再分别分析。

435. 无重叠区间 ​

给定一个区间数组 intervals，其中 intervals[i] = [starti, endi]。你需要移除最少数量的区间，使剩余区间互不重叠。

题目规定端点相接不算重叠，因此 [1,2] 和 [2,3] 可以同时保留。

查看示例与约束

输出：1
解释：移除 [1,3] 后，剩余区间互不重叠。

约束

  • 1 <= intervals.length <= 10^5
  • intervals[i].length == 2
  • -5 * 10^4 <= starti < endi <= 5 * 10^4

思路 ​

最少删除的区间数可以转换为：

最少删除数 = 区间总数 - 最多能保留的互不重叠区间数

为了保留尽可能多的区间，每次优先选择结束最早的区间。结束越早，留给后续区间的空间越大。

为什么可以优先选择结束最早的区间？假设某个最优方案在当前可选区间中先选择了 A，而 B 是其中结束最早的区间。因为 end(B) <= end(A)，原来能排在 A 后面的区间也一定能排在 B 后面。把 A 换成 B 不会减少最终能够保留的区间数量，因此这个选择是安全的。

实际扫描时，先保留排序后的第一个区间，并用 end 记录它的右端点。之后依次检查剩余区间：

  • 如果 start >= end，当前区间可以接在上一个保留区间之后，因此保留它，并将 end 更新为当前区间的右端点。
  • 如果 start < end，当前区间与上一个保留区间重叠。由于区间已经按右端点排序，当前区间不会结束得更早，保留它也不能给后面留下更多空间，因此直接跳过当前区间。

代码（JavaScript） ​

js
var eraseOverlapIntervals = function (intervals) {
  if (intervals.length <= 1) return 0;

  intervals.sort((a, b) => a[1] - b[1]);

  let keep = 1;
  let end = intervals[0][1];

  for (let i = 1; i < intervals.length; i++) {
    const [start, curEnd] = intervals[i];

    if (start >= end) {
      keep++;
      end = curEnd;
    }
  }

  return intervals.length - keep;
};

复杂度 ​

  • 时间复杂度：O(n log n)，主要来自排序。
  • 空间复杂度：扫描本身为 O(1)；整体取决于 JavaScript 引擎的排序实现。例如 V8 的 Array.prototype.sort 使用 Timsort，最坏需要 O(n) 额外空间。

452. 用最少数量的箭引爆气球 ​

若干球形气球贴在用 XY 平面表示的墙上，points[i] = [xstart, xend] 表示第 i 个气球水平直径的左右端点，气球的纵坐标未知。一支箭可以从某个 x 坐标垂直射出并一直前进；只要 xstart <= x <= xend，箭就能引爆该气球。箭的数量不限，要求返回引爆全部气球所需的最少箭数。

约束

  • 1 <= points.length <= 10^5
  • points[i].length == 2
  • -2^31 <= xstart < xend <= 2^31 - 1

思路 ​

和 435 一样，先把区间按右端点从小到大排序。不同的是，这里不是保留区间，而是把箭放在合适的位置，让一支箭尽可能射中更多气球。

对于当前结束最早的气球，至少需要一支箭射中它，因此把箭放在它的右端点 end。由于区间已经按右端点排序，后面气球的右端点一定大于或等于 end。把箭放在 end，既能射中当前气球，又能尽可能覆盖后面的气球：如果后面气球的 start <= end，end 也在它的区间内，可以共用这支箭；只有当 start > end 时，才需要新增一支箭。

实际扫描时，用 arrow 记录当前这支箭的位置：

  • 如果 start <= arrow，当前气球能被这支箭射中，继续检查下一个气球。
  • 如果 start > arrow，当前气球位于这支箭的右侧，需要新增一支箭，并把它放在当前气球的右端点。

代码（JavaScript） ​

js
var findMinArrowShots = function (points) {
  if (points.length === 0) return 0;

  points.sort((a, b) => a[1] - b[1]);

  let arrows = 1;
  let arrow = points[0][1];

  for (let i = 1; i < points.length; i++) {
    const [start, end] = points[i];

    if (start > arrow) {
      arrows++;
      arrow = end;
    }
  }

  return arrows;
};

边界条件 ​

箭射在区间端点时也能引爆气球，因此 start <= arrow 时可以共用当前这支箭；只有 start > arrow 时才需要新增一支箭。这里的等号不能遗漏。

  • 空间复杂度：扫描本身为 O(1)；整体取决于 JavaScript 引擎的排序实现。例如 V8 的 Array.prototype.sort 使用 Timsort，最坏需要 O(n) 额外空间。
