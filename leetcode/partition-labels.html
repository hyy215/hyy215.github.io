划分字母区间（Partition Labels） ​

Algorithm贪心字符串

例题：763. 划分字母区间 ​

给定一个字符串 s，将它划分成尽可能多的连续片段，使同一个字母最多只出现在一个片段中。各片段按原顺序拼接后必须仍然等于 s，最后返回每个片段的长度。

例如，"ababcc" 可以划分为 ["abab", "cc"]；["aba", "bcc"] 会让 b 跨片段出现，而 ["ab", "ab", "cc"] 同样不合法。

以下题意、示例与约束参考 LeetCode 763. 划分字母区间。

查看示例与约束

示例 1

text
输入：s = "ababcbacadefegdehijhklij"
输出：[9,7,8]
解释：划分结果为 "ababcbaca"、"defegde"、"hijhklij"。只切成 "ababcbacadefegde" 和 "hijhklij" 虽然合法，但片段数更少。

约束

  • 1 <= s.length <= 500
  • s 只包含小写英文字母

思路 ​

题目要求“同一字母最多出现在一个片段中”，这意味着：

如果某个片段里包含字符 c，那么这个片段必须一直延伸到 c 最后一次出现的位置。

所以第一步先遍历字符串，记录每个字符最后出现的下标：

txt
last[c] = 字符 c 在 s 中最后一次出现的位置
1

第二步从左到右扫描字符串，维护两个变量：

  • start：当前片段的起点。
  • end：当前片段必须覆盖到的最远位置。

扫描到下标 i 时，字符是 s[i]，当前片段必须至少覆盖到 last[s[i]]。因此更新：

js
end = Math.max(end, last[s[i]]);
1

当 i === end 时，说明从 start 到 end 这一段里所有字符的最后出现位置都已经被覆盖了：

  • 这段内部的字符不会在后面再出现；
  • 因此可以在这里切一刀；
  • 片段长度是 end - start + 1；
  • 下一段从 i + 1 开始。

这就是贪心成立的地方：一旦能切就立刻切。i === end 表示当前位置是当前片段能够结束的最早位置；在此之前，至少有一个已经扫描过的字符还会在右侧出现，因此提前切分一定不合法。在 end 处立即切分，可以为剩余字符串保留尽可能多的切分机会；继续向后扩展只会合并原本可以分开的内容，不可能得到更多片段。

代码（JavaScript） ​

js
var partitionLabels = function (s) {
  const last = new Array(26).fill(0);
  const base = 'a'.charCodeAt(0);

  for (let i = 0; i < s.length; i++) {
    last[s.charCodeAt(i) - base] = i;
  }

  const ans = [];
  let start = 0;
  let end = 0;

  for (let i = 0; i < s.length; i++) {
    const index = s.charCodeAt(i) - base;
    end = Math.max(end, last[index]);

    if (i === end) {
      ans.push(end - start + 1);
      start = i + 1;
    }
  }

  return ans;
};

复杂度 ​

  • 时间复杂度：O(n)。先遍历一次记录最后位置，再遍历一次切分。
  • 空间复杂度：O(1)。字符集固定为 26 个小写英文字母。
