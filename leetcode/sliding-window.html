滑动窗口 ​

Algorithm滑动窗口

适用场景 ​

滑动窗口常用于处理数组或字符串中的连续子数组或子串问题。它在移动边界时复用上一个窗口的计算结果，避免对每个区间重新统计。常见目标包括计算固定长度区间的最大值或总和，以及寻找满足条件的最长或最短区间。

滑动窗口并不适用于所有连续区间问题。例如数组包含负数时，窗口和不再随边界移动保持单调，简单的“右扩、左缩”通常无法解决区间和恰好为 k。这类问题通常使用前缀和与哈希表，处理过程如下：

  1. 遍历数组，计算从数组开头到当前位置的总和 sum。
  2. 在哈希表中查找前缀和 sum - k。如果它此前出现过，说明它所在位置的下一个元素到当前位置之间的区间和为 k。
  3. 根据 sum - k 的出现次数累加答案。
  4. 将当前前缀和 sum 记录到哈希表中，供后续位置查找。

常见做法 ​

根据窗口长度和收缩时机，常见做法分为三类：

类型边界移动方式示例
固定长度窗口right 加入新元素；窗口长度超过 k 时，移动 left 移出最左侧元素计算长度为 k 的子数组的最大总和
最长合法窗口right 扩展窗口；窗口违反限制时，移动 left，直到窗口重新合法寻找无重复字符的最长子串
最短达标窗口right 扩展窗口；窗口满足目标后，移动 left，在保持达标的前提下尽量缩短窗口在非负数数组中寻找和大于等于目标值的最短子数组

窗口内的状态通常用总和、计数器、Set 或 Map 维护。只要加入和移出元素时能够快速更新状态，并且 left、right 都只向右移动，整体时间复杂度通常可以降到 O(n)。

例题：3. 无重复字符的最长子串 ​

给定字符串 s，返回不含重复字符的最长子串的长度。

查看示例与约束

示例 1

text
输入：s = "abcabcbb"
输出：3
解释：最长无重复子串的长度为 3，"abc"、"bca" 和 "cab" 都满足条件。

约束

  • 0 <= s.length <= 5 * 10^4
  • s 由英文字母、数字、符号和空格组成

思路 ​

使用 Set 记录窗口 [left, right] 内的字符，并始终保证窗口中没有重复字符：

  1. 向右移动 right，检查准备加入窗口的字符 s[right]。
  2. 如果 s[right] 已在 Set 中，说明窗口内出现重复。不断从 Set 中删除 s[left]，同时增大 left，直到重复字符被移出窗口。
  3. 将 s[right] 加入 Set。此时窗口重新满足无重复条件，用 right - left + 1 更新最长长度。

第 2 步必须使用 while 而不是 if，因为重复字符可能位于窗口中间，需要连续移出多个字符才能恢复合法窗口。

如果已经确认输入只包含 ASCII 字符，也可用长度为 128 的布尔数组或计数数组代替 Set，进一步降低常数因子；这一优化不能直接用于任意 Unicode 字符串。

时间复杂度为 O(n)：right 遍历字符串一次，left 在整个过程中最多移动 n 次。Set 最多保存窗口中的所有不同字符，因此额外空间复杂度为 O(min(n, |Σ|))，其中 |Σ| 表示字符集大小。

动画演示 ​

图 1：紫色区域表示当前候选窗口。纳入右侧新字符后，候选窗口可能短暂包含重复字符；随后左边界右移，直到窗口重新满足无重复条件。

代码（TypeScript） ​

ts
function lengthOfLongestSubstring(s: string): number {
  const set = new Set<string>();
  let left = 0;
  let maxLength = 0;

  for (let right = 0; right < s.length; right++) {
    while (set.has(s[right])) {
      set.delete(s[left]);
      left++;
    }
    set.add(s[right]);
    maxLength = Math.max(maxLength, right - left + 1);
  }

  return maxLength;
}
