排序算法 ​

Algorithm排序

本文用 JavaScript 记录冒泡、选择、插入、快速和归并五种经典排序算法，重点比较它们的基本思路、复杂度、稳定性与实现方式。

一、整体对比 ​

算法最好时间平均时间最坏时间额外空间稳定性
冒泡排序（带提前终止）O(n)O(n²)O(n²)O(1)稳定
选择排序O(n²)O(n²)O(n²)O(1)不稳定
插入排序O(n)O(n²)O(n²)O(1)稳定

“稳定”表示排序不会打乱相同排序值之间原有的先后顺序。例如按成绩升序排列下面三名学生：

二、冒泡排序 ​

冒泡排序反复比较相邻元素：若前一个元素大于后一个元素，就交换它们。一轮结束后，当前未排序区间中的最大元素会移动到末尾；之后每轮继续缩小未排序区间。

如果某一轮没有发生任何交换，说明数组已经有序，可以提前结束。这个优化使有序输入的时间复杂度降为 O(n)。

图 1：冒泡排序过程。来源：菜鸟教程 · 冒泡排序。

js
function bubbleSort(arr) {
  for (let end = arr.length - 1; end > 0; end--) {
    let swapped = false;

    for (let i = 0; i < end; i++) {
      if (arr[i] > arr[i + 1]) {
        [arr[i], arr[i + 1]] = [arr[i + 1], arr[i]];
        swapped = true;
      }
    }

    if (!swapped) break;
  }

  return arr;
}

三、选择排序 ​

选择排序把数组分成“已排序前缀”和“未排序后缀”。每一轮从未排序后缀中找出最小元素，再把它交换到当前起始位置。

图 2：选择排序过程。来源：菜鸟教程 · 选择排序。

js
function selectionSort(arr) {
  for (let i = 0; i < arr.length - 1; i++) {
    let minIndex = i;

    for (let j = i + 1; j < arr.length; j++) {
      if (arr[j] < arr[minIndex]) {
        minIndex = j;
      }
    }

    if (minIndex !== i) {
      [arr[i], arr[minIndex]] = [arr[minIndex], arr[i]];
    }
  }

  return arr;
}

无论输入是否有序，选择排序都要扫描完整的未排序区间，所以最好、平均和最坏时间复杂度都是 O(n²)。远距离交换可能改变相同排序值之间的原有顺序：例如按成绩排列“小明(90)、小刚(90)、小红(80)”时，第一轮交换后会变成“小红(80)、小刚(90)、小明(90)”。因此，经典选择排序不稳定。

四、插入排序 ​

插入排序维护左侧的已排序前缀。每次取出下一个元素，把所有比它大的前缀元素向右移动一位，再将它放入空出的位置。

图 3：插入排序过程。来源：菜鸟教程 · 插入排序。

js
function insertionSort(arr) {
  for (let i = 1; i < arr.length; i++) {
    const current = arr[i];
    let j = i - 1;

    while (j >= 0 && arr[j] > current) {
      arr[j + 1] = arr[j];
      j--;
    }

    arr[j + 1] = current;
  }

  return arr;
}

五、快速排序 ​

快速排序先选择一个基准值（pivot），再把其余元素分成小于基准的左数组和大于等于基准的右数组，最后递归排序左右两部分并拼接结果。

下面的实现使用辅助数组换取更直观的代码，不会修改输入数组。

图 4：快速排序过程。来源：菜鸟教程 · 快速排序。

js
function quickSort(arr) {
  if (arr.length <= 1) {
    return arr.slice();
  }

  const pivotIndex = Math.floor(arr.length / 2);
  const pivot = arr[pivotIndex];
  const left = [];
  const right = [];

  // 跳过基准元素，将其余元素分到左右数组。
  for (let i = 0; i < arr.length; i++) {
    if (i === pivotIndex) continue;

    if (arr[i] < pivot) {
      left.push(arr[i]);
    } else {
      right.push(arr[i]);
    }
  }

  return [...quickSort(left), pivot, ...quickSort(right)];
}

复杂度与边界 ​

  • 平均时间复杂度： 基准能把数组大致均分时，递归深度为 O(log n)，每层划分处理 O(n) 个元素，总时间为 O(n log n)。
  • 最坏时间复杂度： 如果基准持续成为当前数组的最小值或最大值，每次只能减少一个元素，时间复杂度会退化为 O(n²)。
  • 额外空间： 均衡划分时，同时保留的辅助数组合计为 O(n)；持续极端划分时，多层递归会同时保留长度依次递减的数组，最坏为 O(n²)。
  • 稳定性： 与基准相等的元素会进入右数组，而基准会排在它们前面，因此可能改变相同排序值之间的原有顺序。

常见优化方向 ​

  • 改进基准选择： 随机选择基准或使用首、尾、中三数取中，可以降低持续出现坏划分的概率，但不能消除理论上的最坏情况。
  • 改用原地划分： 可以减少辅助数组，但指针和边界处理会更复杂。
  • 处理重复值： 重复值很多时，可以划分为小于、等于和大于基准的三部分，避免相等元素不断进入同一侧。
  • 小区间切换到插入排序： 子区间较短时，插入排序通常具有更小的常数开销；具体阈值应根据运行环境实测。

六、归并排序 ​

归并排序是分治思想的典型代表：把数组不断拆成两半，直到每个子区间只剩一个元素，再把相邻的有序区间两两合并，最终得到完整的有序数组。

无论输入是否有序，归并排序的时间复杂度都为 O(n log n)。合并需要 O(n) 的辅助空间；当左右元素相等时优先取左侧元素，就能保持稳定性。

图 5：归并排序过程。来源：菜鸟教程 · 归并排序。

合并步骤是递归版和迭代版共同的核心：使用双指针比较两个相邻有序区间，把较小的元素写入辅助数组。相等时优先写入左区间的元素，以保持稳定性。

js
function mergeRanges(source, target, start, middle, end) {
  let left = start;
  let right = middle;
  let write = start;

  // 两边都有元素时，每次取较小的一个。
  while (left < middle && right < end) {
    if (source[left] <= source[right]) {
      // 相等时先取左边，保持排序的稳定性。
      target[write++] = source[left++];
    } else {
      target[write++] = source[right++];
    }
  }

  // 其中一边取完后，复制另一边的剩余元素。
  while (left < middle) {
    target[write++] = source[left++];
  }

  while (right < end) {
    target[write++] = source[right++];
  }
}

自顶向下（Top-Down，递归） ​

自顶向下的写法从整个数组出发，先递归地排好左右两半，再借助一个与输入等长的辅助数组合并相邻区间。递归调用栈直接表达了“先拆分、再合并”的过程。

js
function mergeSortTopDown(arr) {
  const buffer = new Array(arr.length);

  function sort(start, end) {
    if (end - start <= 1) return;

    const middle = start + Math.floor((end - start) / 2);
    sort(start, middle);
    sort(middle, end);
    mergeRanges(arr, buffer, start, middle, end);

    for (let i = start; i < end; i++) {
      arr[i] = buffer[i];
    }
  }

  sort(0, arr.length);
  return arr;
}

拆分与合并的过程（以 [5, 2, 4, 1] 为例）：

  • 优点： 写法简洁，最贴近分治定义。
  • 代价： 除 O(n) 辅助数组外，还有 O(log n) 的递归栈。

自底向上（Bottom-Up，迭代） ​

自底向上的写法不使用递归：先把每个元素视为长度为 1 的有序块，再让块长按 1、2、4、8…… 翻倍，逐轮合并相邻块。

下面使用两个等长数组交替作为读取区和写入区。每一轮只线性读写全部元素，不在内层循环反复拼接已经生成的结果。

js
function mergeSortBottomUp(arr) {
  const n = arr.length;
  if (n <= 1) return arr;

  let source = arr;
  let target = new Array(n);

  for (let width = 1; width < n; width *= 2) {
    for (let start = 0; start < n; start += 2 * width) {
      const middle = Math.min(start + width, n);
      const end = Math.min(start + 2 * width, n);
      mergeRanges(source, target, start, middle, end);
    }

    // 下一轮读取本轮结果，并复用原来的读取数组作为写入区。
    const temp = source;
    source = target;
    target = temp;
  }

  if (source !== arr) {
    for (let i = 0; i < n; i++) {
      arr[i] = source[i];
    }
  }

  return arr;
}

每一轮的块长翻倍（以 [5, 2, 4, 1, 6, 3] 为例）：

  • 优点： 无递归调用栈，时间复杂度稳定为 O(n log n)。
  • 代价： 需要 O(n) 辅助数组，下标和块边界处理比递归版更繁琐。
  • 链表场景： 自底向上的归并思想也适合链表，但需要使用链表节点拆分与合并的独立实现，不能直接套用上面的数组代码。

两种归并实现对比 ​

维度自顶向下（递归）自底向上（迭代）
拆分方式递归二分从单元素块开始逐轮合并
控制流递归调用双层循环、块长翻倍
额外空间O(n) + 递归栈 O(log n)O(n)，无递归栈
时间复杂度O(n log n)O(n log n)
适用场景通用、直观、易读希望避免递归调用栈的数组排序

七、如何选择 ​

  • 数据规模较小或基本有序时，可以优先考虑插入排序。
  • 需要稳定且最坏时间为 O(n log n) 时，可以使用归并排序，但要接受 O(n) 辅助空间。
  • 一般内存数组排序可以考虑快速排序；使用确定性基准时，需要了解最坏时间和递归栈风险。
  • 冒泡排序和选择排序更适合用于理解基础过程，不适合大规模数据。

比较排序算法时，不应只看平均时间复杂度，还要同时考虑输入分布、稳定性、额外空间、递归深度以及函数是否修改输入。
